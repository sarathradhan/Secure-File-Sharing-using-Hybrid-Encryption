THE SECURITY DESIGN

Four layers, one protected file.

01 — 04
  1. 01

    Encrypt the file

    AES-256-GCM protects file contents and authenticates the encrypted data.

    AES-256-GCM
  2. 02

    Wrap the secret key

    RSA-2048 protects the AES key so only the intended receiver can recover it.

    RSA-2048
  3. 03

    Check integrity

    A SHA-256 digest helps detect unexpected changes to the file.

    SHA-256
  4. 04

    Verify the sender

    A digital signature lets the receiver verify who sent the file.

    RSA SIGNATURE
