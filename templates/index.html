CRYPTOGRAPHY & NETWORK SECURITY

Secure file sharing
over your local network.

One Flask process hosts the web application and relays traffic. Every open browser is an independent endpoint with its own cryptographic identity.

i

Secure transfer enabled
Each browser keeps its own private keys. Files are encrypted and signed in the browser before Flask relays the package; the receiving browser decrypts and verifies it.

  3. 03

    Private keys stay local

  4. 04

    Browsers discover each other

    A browser appears here only after it successfully reaches this Flask server and registers.

    PUBLIC KEY
  5. 05

    Files are encrypted at the browser endpoints

    AES-256-GCM protects the file, RSA-OAEP protects the AES key, SHA-256 checks integrity, and RSA-PSS authenticates the sender.
